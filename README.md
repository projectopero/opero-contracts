# opero-contracts

On-chain receipt anchoring and settlement contracts for
[Project Opero](https://github.com/projectopero).

This repository holds the Solidity contracts that anchor Opero's signed
execution receipts on-chain and settle strategy attribution. Contracts are
published here for review and independent verification.

Status: pre-production. Contracts and deployment addresses are being published
here as they are finalized.
